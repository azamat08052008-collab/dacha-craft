Privacy Policy

Last updated: October 29, 2026

“Dacha Craft Uploader” is a private tool used only by the owner of the Dacha Craft channels. It is not offered to other users.

What data the tool accesses

With the channel owner's permission, the tool uses YouTube API Services to upload videos to the owner's own YouTube channel and to read that channel's statistics and YouTube Analytics reports (views, watch time, audience countries). It also uses the TikTok API to read the owner's own TikTok profile and video statistics (followers, views, likes, comments, shares).

How the data is used and stored

The data is used only to publish the channel's own videos and to send the owner a daily statistics summary. Access tokens are stored privately by the owner. No data is sold, shared with third parties, or used for advertising.

Google API Services

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. See also the YouTube Terms of Service and the Google Privacy Policy. TikTok data is used under the TikTok Developer Terms.

Revoking access

Access can be revoked at any time on the Google security settings page.

Contact

Questions: through the contact details on the Dacha Craft YouTube channel.
